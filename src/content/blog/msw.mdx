MSW (Mock Service Worker) is an API mocking library that supports us mocking out network requests.
This tool has become somewhat of the defacto tool for mocking as it allows us to build resilient user interfaces,
and ACTUALLY test their behavior without having to test everything under the sun manually. At least for React,
this allows us to really accelerate how we write our Jest tests.

See more about the tool at [https://mswjs.io/](https://mswjs.io/).
